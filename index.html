Adding a script. Drop a .js file in extensions/ with a // @name, // @description, // @match and // @tag header, then run python3 tools/build_index.py. Push, and it appears here.

Scripts are plain userscripts — the only extension format these browsers run. There is no chrome.* API here, so Chrome extensions will not work, whatever the store says.
