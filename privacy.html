Privacy and security

The Nijatva Web Store is a catalogue of small scripts. This page says plainly what the store does and does not do. संक्षेप में: यह स्टोर कोई डेटा इकट्ठा नहीं करता।

What the store page does

  • Does not use analytics, advertising or tracking scripts.
  • Loads the list of scripts (index.json) and the script files from GitHub Pages and GitHub.
  • Stores only your list of installed scripts and your language and theme choice, in this browser's local storage. Nothing is sent anywhere.
  • GitHub hosts the page and may keep standard server logs under its own privacy policy.

What the scripts can do

Each script says what it can reach, in its own detail sheet under What it can. Scripts run inside the pages you choose to visit. A script with a ! mark does something that goes beyond changing how a page looks:

  • YouTube dislikes sends the ID of each video you open to a third-party service, returnyoutubedislikeapi.com, to get the count.
  • Cookie accept clicks the "accept" button on cookie banners for you. Read the banner first if you care what you agree to.
  • Media finder reads the video and audio links on a page so the app's media tools can use them. It sends them to the app only.
  • Background play makes a page believe it is always visible, so video can keep playing.

Scripts that are never allowed

  • No script may add visible ads, links or content to a page.
  • No script may send your browsing history, passwords or form input anywhere.
  • Every script in the store is public source code. You can read it before you install it, and the install is refused if the file no longer matches the SHA-256 checksum in the catalogue.

Your choices

  • Remove a script at any time from the app's Extensions page.
  • Install from a copied link instead of the one-tap button if you want to check the file first.
  • Report a problem by opening an issue on GitHub.
